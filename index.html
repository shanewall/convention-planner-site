Draw the room. Count the seats. Staff the event. Print the plan.

A free floor-planning tool built for conventions and assemblies. Seating counts itself, sightlines show who can see the stage, and the whole thing runs in your browser — no account, and your files stay on your device.

Launch Convention Planner Watch the tutorials Free. Works in English and Spanish. Open source under the GPL.

One page, no service, your files

Convention Planner is a single web page, not a subscription. Open it and the whole tool loads into your browser; from there, everything happens on your computer.

Nothing to sign up for

There is no login and no cloud. You open the page and start drawing.

Your project is a file

Saving writes one project file to your device. Share it by handing someone the file — the same way you'd share a spreadsheet.

Private by design

No server stores your plans, so there's nothing to leak. The only thing recorded is an anonymous, city-level count of visits.

What it does

Everything an event floor plan needs, in the vocabulary of events rather than CAD.

Seating that counts itself

Define chair profiles, draw a section as any polygon, and the app fills it with seats and keeps a live count. Reshape it and the number updates as you drag.

Chair Styles

Lasso any chairs — held seats, ADA companion seats, a VIP block — and tag them with a number. A per-page legend tallies each style for the sheet and the whole project.

Screens and sightlines

Place screens with viewing cones and see, chair by chair, who has a clear view before anyone sits down.

Floor plans at true scale

Calibrate a blueprint image or PDF with two known points, or work on a blank sheet at a standard drawing scale. Feet-and-inches or metric, lossless either way.

Measuring and annotation

Dimensions, lines, polylines, boxes, revision clouds, area measurements, callouts, counters, and text — drawn in real units, printed exactly as shown.

Key items and signage

Numbered markers for signs, AV stations, and check-in points, plus a Key Item report so the crew placing things has a list that matches the drawing.

Layers and organization

Group items into layers you can show, hide, or lock together. Set a working layer and everything you draw lands there.

Attendants and staffing

Roster, posts on the plan, shifts, and a chain of command. Print just the slice each captain needs. Import and export with Excel.

Share the file, split the work, merge it back

One person lays out seating while another builds the staff schedule in their own copy. Merge folds the second file into the first — with a preview so you accept exactly what belongs.

Print and export

True vector PDFs that stay sharp at any size, print-to-scale sheets, a Markup PDF that returns a supplied drawing with your work layered on top, and three reports.

Tutorials

Short videos, one chapter at a time. Each opens with the problem it solves, then shows you how. New chapters appear here as they're published.

    Questions

    Does it work offline?

    Yes. From the app's Help menu, download the offline copy — a single file that contains the whole app. Open it in a browser on a machine with no internet and everything works, including PDF import and export.

    Where are my projects stored?

    On your own device, as a file you save and open. Nothing is uploaded anywhere. If you want to collaborate, send someone the file — or use Merge to combine two people's work.

    What does it cost?

    Nothing. It's free to use, and the source code is public under the GPL so anyone can see exactly what it does.

    Which browsers?

    Any current browser — Chrome, Edge, Firefox, or Safari — on a desktop or laptop. It's a drawing tool, so a mouse or trackpad and a reasonably sized screen make it much more comfortable than a phone.

    Can I use it in Spanish?

    Yes. The whole interface, the manual, and the printed reports are available in English and Spanish; switch from the toolbar.

    Found a bug or want a feature?

    Use the Feedback button inside the app, or email feedback@conventionplanner.org. Feedback goes straight to the developer.
